# e-Humure

Team NovaCrew - BSc Software Engineering, Foundations Project (October 2026)

e-Humure helps nurses in rural clinics in Rwanda notice depression in patients
with long-term illnesses (diabetes, hypertension). The nurse asks a few quick
questions. If the answers are worrying, the system scores a full questionnaire
and alerts the psychologist at the district hospital, who can book an
appointment. The patient gets a text message reminder.

The tool supports the nurse and the psychologist. It does not diagnose.
All data in this project is fake. No real patient data is used.

## Folders
- frontend/  the screens the nurse and psychologist use
- backend/   the scoring rules and, later, the server
- database/  the table design
- testing/   fake patients and test results
- docs/      plans, flow diagram, permissions, testing plan
